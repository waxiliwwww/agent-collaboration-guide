# 本地用户配置与安全更新

公开包提供通用方法；安装后的 `local/` 存放本机私有数据。入口是 `local/preferences.md`，正文留当前有效选择与短路由，项目／场景细节按需拆开。已采用的外置入口也可继续使用；不要为统一路径擅自搬动资料或扩大扫描范围。

## 第一次使用与后续读取

用户采用本技能且没有其他配置时，建立 `local/preferences.md`；已有文件不覆盖。只写用户明确的长期选择，不从一次反馈、账号或目录名推断身份与偏好。开始／恢复／切换任务读入口，再读与本次工作有关的部分；同任务未变不重复加载。

明确长期更正及时写回同一位置。本次决定、项目约束、理解假设和通用候选按[反馈闭环](decisions-and-review.md)分流；旧条目撤回或替换时保留来源，历史移到 `local/history/` 而不默认读取。个人数据不因任务完成自动升级为公共方法。

迁移时先备份源文件、核对有效项与冲突、写入新真源并验证；最后将旧入口改成指向新真源的短指针。更新前检查源文件有无他人修改，不维护两份可独立编辑的偏好。不同宿主可以用各自短入口指向同一私有真源，不能假称其中一套配置自动对另一套生效。

## 安装、更新和导出

使用包内 `scripts/update_install.py <源技能目录> <目标目录>`。首次安装可加 `--init-local`，已有安装的 `local/` 不会被读取或覆盖；`--dry-run` 只核对公共文件目的地。脚本只更新公共文件，不删除目标整树，拒绝公开源或目的地的符号链接以避免写到意外位置。异常会报错；必要时从同一源重新执行公共更新，不能把部分更新称为完整成功。

`local/` 与私有历史不进 Git、公开 PR 或发布包。仓库与技能目录都忽略它，但 `.gitignore` 不阻止任意打包器收集私有文件。发布应从干净公开源导出，可用同一脚本复制到全新导出目录且不加 `--init-local`，再检查导出目录没有 `local/`；不要把整个已安装目录直接 zip。用户主动导出个人配置是另一项明确授权。

本脚本只保证本更新流程保留私有目录；其他安装器若先删除整目录仍会丢数据。使用其他更新器前先核其保留行为，必要时备份并恢复，不声称通用生态已自动支持。

# 可选技能与资源

按实际任务选用，不因推荐就安装、联网、读取全部材料或叠加流程。先确认当前环境是否已有所需能力；专用技能负责产物制作，本规约负责目标、交接与验收，两者不重复访谈。使用第三方技能时遵守其适用范围，用户要求仍优先。

| 需要 | 可选资源 | 使用边界 |
| --- | --- | --- |
| 单文件 HTML 横向演示、杂志／瑞士风格、演讲者模式 | [guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill) | 演示制作技能。先形成内容主线与代表页；不是所有说明文档都要做成 PPT。需要可编辑 PPTX 时另选满足该格式的工具。 |
| 长文协作、自然表达、减少套话的候选技能 | [de-ai-writing 话题](https://github.com/topics/de-ai-writing) | 是发现入口，不是单个技能或统一质量认证。按语言、用途、保存方式、事实保留与许可判断候选，不能把“检测分数下降”当作内容更清楚或更真实。 |

链接于 2026-11-07 核对；未复制第三方代码或安装新依赖，未做同条件效果比较。独立技能的版本、权限与许可在实际采用时再核对。润色不能删掉必要背景、关联依据、限制或改变作者主张。

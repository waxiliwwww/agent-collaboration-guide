# 按场景复用现成技能

这是执行选用入口，不是收藏清单。先看当前环境已提供的技能名称与描述，按实际能力与输出格式选择；匹配时读其 `SKILL.md` 及必要资源，沿原模板、脚本或方法完成任务，本规约只补目标、授权、交接与证据缺口。不要复制第三方整套规程再维护另一份，也不重复询问已确认信息。简单小事或现有工具已足够时，不增加技能流程。

## 缺失、重叠与冲突

- **缺失：**确有收益时，给出具体技能、来源、匹配理由和预期安装范围；仓库集合或话题先定位到单个技能，不一键安装全部。已有明确安装授权就沿用，否则先建议并取得决定；未安装如实说明，继续可独立完成的工作，不假装调用。
- **重叠：**已有计划、认可样稿、测试和项目脚本直接传入选定技能，复用已完成步骤与有效证据；不因换技能重开访谈、批准或全量验证。不需要的能力不额外叠加。
- **冲突：**用户当前有效要求、项目约定和授权边界优先；第三方技能的默认步骤不自动授权联网安装、付费调用、改写 AGENTS、删除测试或破坏性实验。按被测边界和风险选择必要检查，不能把正常模块隔离一概当成无效替身；不因局部措辞或低影响文档修改强制新建浏览器测试、逐步截图或规则表。不能兼容时说明具体冲突，采用合适的替代方法，仅重要取舍才确认。

链接与使用映射于 2026-11-11 核对，不捆绑第三方实现，不保证外部版本、安装状态或运行能力。实际使用时以本机入口和可用工具为准；本规约即使没有外部技能也能独立使用。
